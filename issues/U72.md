# U72 Dev facades: delete the two forwarding modules

**Wave** follow-up to U60. **Port** 8872. A pure deletion refactor, no behavior change.

U60 left `apps/server/src/room/dev.ts` and `apps/server/src/user/dev.ts` as facades that only forwarded each method to `room/dev-impl.ts` and `user/dev-impl.ts` through `loadRoomDev()` and `loadUserDev()`. This unit deletes both facades and lets each Durable Object hold the lazy dev load itself.
