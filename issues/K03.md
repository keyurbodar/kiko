## Discoveries

- `openTabs` (`app/open-tabs.ts`) is more than the strip's store. It backs close-next, the chat fallback, and reopen. Removing the strip safely means moving that logic first.
- `chat/info/sections.tsx` imports `openTabs` and `nextAfterClose` for chat deletion, so the open-tab logic reaches into the info panel too.
- `files/pane.tsx` keeps a second tab strip (`role="tablist"`, `data-component="file-tabs"`). It goes with the file tab list.
- The `chat.files` command still exists with no chord. It has nothing to open until the Files section exists.
