# K03 layout without tabs

## Report

Done, with one budget failure and one process deviation, both below.

What landed:

- Corvu layout. `@corvu/resizable` 0.2.5 is installed. `app/shell.tsx` is a Corvu Root with sidebar, chat and right panel columns and two handles. Widths persist in `kiko:sidebar-width` and `kiko:info-width` (px), saved on drag end and on key up. The chat column has a 360 px floor. Arrow keys on a handle resize by 16 px. Dragging below the minimum collapses the sidebar or the panel, and dragging out of a collapsed sidebar reopens it. Motion is 0 ms. A window resize puts the saved widths back, because Corvu keeps percentages. The three columns' first sizes come from `initialSizes` in `app/widths.ts` (tested), because Corvu's own first layout does not add up when px sizes are mixed with an unsized panel.
- Both hand-rolled resizers, `@solid-primitives/pointer` and the old width signals in `chat/info/state.ts` are deleted.
- Chat tab strip removed: `tab-strip.tsx`, `tab-strip.css`, `open-tabs.ts` and its test are gone. The top bar shows the active chat's title. Close-next, the route fallback and reopen moved to `sidebar/actions.ts` and `lib/chats.ts` (`chatAfter`, tested): closing or deleting the open chat goes to the next chat in the sidebar list, else the one above, else `/chat`. `Close chat` now means leave the chat (a temporary chat is deleted) and `Reopen closed chat` goes back to the last one left.

One file is open per chat, with a back arrow in the file header. The tree stays mounted behind it.

## Discoveries

- Corvu's panel registration only handles two cases: every panel sized, or the offsets from a total of exactly 1. Adding a panel later shrinks every other panel evenly, not just the chat. So the right column is always mounted (collapsed to 0) and opens and closes through `expand` and `collapse`.
- A new empty file in the Files section shows "The server said 416" in the viewer. It is the empty file's range read, not from this change, and I did not chase it.
- Vite hot reload of `panel.tsx` loads a second copy of `state.ts` for the lazy chunk, so the panel's close button seemed dead until a full reload. It does not happen in a build.
- `docs/architecture.md` still describes tabs and the old resizers. Not edited here, as it is outside this unit's scope.
