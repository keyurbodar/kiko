# U55 Server tests leave nothing in /tmp

**Model** DeepSeek V4.1 Flash high. **Wave** 7. **Timebox** 45 min.

## Why

Every server test file leaves one `miniflare-*` directory in `/tmp`, even though each test calls `mf.dispose()`. Proven: running `bun test test/alarm.test.ts` once added one directory that no process held. Overnight gate runs left 1,006 of them, 6 GB, and filled the 7.9 GB tmpfs. Servers then failed with `No space left on device` and suites hung.

## Do

In `apps/server/scripts/test-each.ts`, give each spawned `bun test` process its own temp directory: create it, pass it as `TMPDIR` in the spawn's `env` (keep the rest of `process.env`), and remove it with `rm -rf` when the process exits, whether it passed, failed, or was killed for a timeout. This covers every test file without touching any of them. Do not change the tests.

## Acceptance

- Count `/tmp/miniflare-*` before and after `bun run --cwd apps/server test -- alarm` (the runner's file filter). The count must not grow. Show both counts in your report, and show that it grew by one on the old code.
- `bun scripts/check.ts` green after merging `main`.
