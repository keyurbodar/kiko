# U63 Agent runtime: abort before submit, stoppable declared on the tool

**Model** Claude Haiku 5.5 medium. **Wave** 8. **Timebox** 120 min. **Port** 8863.

Source: review B (`issues/review/B.md`) B06 to B10, and U61's follow-ups (`issues/U61.md`, Report).

## Do

1. **B06.** `core/agent/src/host.ts` (~307-311, 358-360): the abort of a stoppable tool goes out after `root.submit` and `inbox.submitted`, so a crash between them leaves the tool running with no abort. Issue the abort before submit. Test in `core/agent` that fails on the old order.
2. **B08.** Stoppability lives in three places: the tool effect, `STOPPABLE_TOOLS` in `core/agent/src/mid-run.ts`, and the `interruptible` callback. Declare it once, on the tool (a `stoppable: true` field next to its effect, or derive it from the `read` effect if every read tool is stoppable; pick the one that deletes more). Delete the list, the option, the dead `!interruptible` guard, and `ask` from the list (it adds nothing on the human path). Fix the two false comments (`apps/server/src/agent/factory.ts:57-58`, `core/agent/src/host.ts:111`). Rewrite `stoppable.test.ts` against real tool definitions, not a hand-built map.
3. **B09.** `stoppableTools` reads entries for every running tool serially. Record `callId -> name` at `tool_execution_start` in the outbox and read that.
4. **B07.** `apps/server/src/agent/agent-do.ts` (~130-134) interrupts asks before the message is admitted. Interrupt only after admission, so a refused message stops nothing. Test.
5. **B10.** `agent-do.ts`: one wipe-guard idiom (two exist), guard `setModel`, assign `this.effects` once.
6. **U61 follow-ups.** Add a slow write-effect fake tool to `apps/server/src/agent/dev-fake.ts` and a `mid-run` suite case where a human message during it does not stop it (it runs to its end, then the answer covers both turns). If a check-level workerd test of the `AgentDO` interrupt wiring (G06) is reachable with the faux model in `apps/server/test`, add it so `interruptible`-style regressions fail `bun run check`; otherwise say why in DEVIATIONS.

SCOPE: `core/agent/src/**`, `core/agent/test/**`, `apps/server/src/agent/**`, `apps/server/test/**` for agent tests, `apps/cli/src/verify/suites/mid-run.ts`, `docs/architecture.md` lines that describe stoppability.
