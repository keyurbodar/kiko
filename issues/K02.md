## Verdict on the plain defaults

The plain defaults are not minimal and modern. They are cute.

- No props are drawn, so the default avatar is clean and calm. Each flavour still carries its own art: jam caps, berry pearls, sparkles, dust, blush dots, and round glossy eyes.
- Those flavour toppings decide the look more than charms or outfits do. The defaults keep the toppings.
- Recommendation for K07: pin the Kiko default flavour to a plainer subset, for example `hatsuyuki`, or use the existing `collection` option. The Kiko brief asks for calm, modern, minimal. The current defaults miss that brief.

## Discoveries

- `resolve` picks a flavour before it applies the defaults. Any caller that uses `resolve` directly gets charms and outfits. Only `avatar`, `avatarUri`, and `Avatar` get the Kiko defaults. K07 must use those.
- The seasonal presets in the library conflict with the defaults. This is a product decision for K07.
