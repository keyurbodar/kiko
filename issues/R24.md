# R24: browser audit and fixes

Paths are under `apps/server/src` unless they start with `core/`. Line numbers are from the code at the start of the unit (main at 00ff3056).

## Audit

### Bugs

| # | Where | Problem |
| --- | --- | --- |
| B1 | `agent/browser/connection.ts:256-270` (`idle`) | Idle closes only the current tab. Tabs the agent opened with `browser_tabs open` and switched away from (`parked`) are cleared from memory and never closed. The next CDP connection cannot adopt them (`core/browser/src/cdp/browser.ts:96`, only tabs it created or opened from a known tab), so they leak in the browser until the browser is reaped, and they cost memory in a 1 GB headless browser. |
| B2 | `agent/browser/connection.ts:35` (`current`), `agent/agent-do.ts:625` | One `BrowserConnection` per agent, one `current` tab. The agent's talker runs up to 3 workers. Two workers that browse at once navigate the same tab and read each other's pages. "Own tabs per agent" is not "own tabs per worker". |
| B3 | `integrations/kernel/lease.ts:21` (`reapDecision`) | A takeover never expires. If the human opens the live view and walks away, every agent's browser tool answers "The human is using the browser" and the reaper looks again each minute for ever. |
| B4 | `integrations/kernel/lease.ts:147` (`switchMode`) | The switch to headful keeps `row.tabs` in the new row, but none of those tabs exist in the new browser. They count against the 8-tab cap until each agent touches again. An agent that is idle holds phantom tabs until its idle release. |
| B5 | `agent/browser/deciders.ts:77-80` (`pickDecider`) | Judge failures are fatal. `jevDecider` throwing (TypeSafe 401, 5xx, no classifier model) ends a `browser_run` task as `crashed`. `jevRanker` throwing fails the whole `browse` call that has `find`. The escalation to the agent's model happens only for low confidence, not for an error. |
| B6 | `agent/agent-do.ts:638-648` (`browserDecider`) | `listProviders` and `turnContext` are not guarded. An RPC error while looking for a judge key fails `browse` with `find` and `browser_run`, with a judge key or without one. |
| B7 | `agent/browser/tools.ts:339` (`browser_share`) | The tool says "you never see a link". The agent cannot send the live view link, which is the owner's report. The request is a plain message with no link, so the human must find the chip. |
| B8 | `agent/browser/tools.ts:121`, `:29` | Rules tell a worker to call `browser_share`. A worker never posts to the chat and cannot tell the human how to take over. |
| B9 | `agent/browser/tools.ts:331-337` (`browser_look`) | The screenshot goes only to the model, and only when the model reads images. An agent cannot post it to the chat. |

### Design gaps

| # | Where | Gap |
| --- | --- | --- |
| D1 | `agent/factory.ts:60` | The whole browser extension is worker-only, so the talker has no way to get the live link, see tabs, or ask for a takeover without starting a worker (a model turn and a worker for one RPC). |
| D2 | `agent/browser/tools.ts:23-30` | The browser guide is six terse lines that do not say: when to use `web_fetch`, how the tab tools fit together, how to share the live view, what control ids are, what a takeover does, how to close tabs. |
| D3 | `agent/browser/tools-more.ts:35-60` (`browser_tabs`) | No `close_all`. No owner or title column for the agent. No forward or reload (`core/browser/src/page/act.ts:189` has only `back`). |
| D4 | `integrations/kernel/connect.ts:46`, `integrations/kernel/lease.ts` | Control is a boolean `takeover`. It works, but it has no time limit and is read in three places (`reapDecision`, `KernelWiring.takeover`, `browserState`). |
| D5 | `agent/browser/lease.ts`, `agent/browser/connection.ts:108` | Tab ownership is by CDP connection (each agent adopts only its own tabs), which is right, but other agents' tabs are invisible to an agent, so `Busy` can only name slugs and counts. |
| D6 | `agent/browser/connection.ts:7` | A socket idle for 15 s closes the agent's tab. A model turn is often longer, so the page state is lost between steps and only the current tab is reopened (at its last URL). Not changed here: the 15 s is a Durable Object duration cost choice. Recorded as a follow-up. |

### Performance gaps

| # | Where | Gap |
| --- | --- | --- |
| P1 | `agent/browser/tools.ts:241` (`browser_act`) | One `paused()` UserDO call per step, up to 10 per `browser_act`, and one per decision in `browser_run` (`:288`). Each is a subrequest, and Free allows 50 per invocation. |
| P2 | `agent/browser/tools.ts:198` (`browse`) | `deps.decider()` runs only for a ranker, but it makes 2 to 3 UserDO RPCs and builds a Jev port. With no judge key the ranker is lexical and none of that is needed. |
| P3 | `core/browser/src/cdp/browser.ts:150-153` (`listTabs`) | Two CDP round trips per tab (`url()` and `title()`, each `Target.getTargetInfo`). `Target.getTargets` answers all tabs in one. `switchTo` and `closeTab` call it to find one tab. |
| P4 | `agent/browser/connection.ts:108` (`slots`) | One `state()` UserDO call per open. The cap race (U21) stays: an open in flight is not visible to another agent until it touches. |

### Judge key dependencies (every place)

- `agent/agent-do.ts:640-646`: picks a judge provider and its auth. Unguarded RPCs (B6).
- `agent/browser/deciders.ts:48-80`: `jevPort`, `pickDecider`. No fallback on error (B5).
- `core/browser/src/decide/jev.ts`, `core/browser/src/plan/rank.ts:60` (`jevRanker`): throw out of the caller (B5).
- `agent/browser/tools.ts:198`, `:278`: ask for the decider (P2).
- Without a judge key the path is `modelDecider(own model)` and `lexicalRanker`. It already exists; it had no test and the two failure paths above.
