7. Tokens

Main already generates the palette block in index.css from packages/theme/src/palette.ts (gen-palette.ts), and a test checks it. That part is sound. Three real problems remain:

  • 256 custom properties in index.css, and about 250 ad-hoc color-mix() calls in component CSS, so components invent their own shades.
  • --accent is a grey hover fill, while the real accent is --ring.
  • The boot script in index.html hard-codes its own colours.

The PR makes the first problem worse (274 properties, plus --surface, --frame-*, --composer-edge, --line-w, --press-edge, --reaction-bg). It also changes the default theme to warm and tints every neutral with the accent. Plan: rename by role, collapse the fills into a small scale, and move component color-mix calls onto roles. The default palette doesn't change.
