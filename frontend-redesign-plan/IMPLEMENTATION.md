# UI redesign implementation

This file supersedes the older design proposals in this directory. The HTML galleries and original audit remain as the decision history.

## Selected design

- Bokeh onboarding with one centered card and the L1 leaf mascot. Clerk owns hosted sign-in. The hosted flow has Sign in, Cloudflare, and Provider. Self-hosted uses Sign in and Provider. Model selection is part of Provider and saves optimistically.
- Moonlit sidebar band with the existing main theme roles. Its background uses the same 8% accent over sidebar mixture as main. The moon and stars use the live foreground, background, and accent. Light, dark, built-in accents, and imported palettes share this path.
- One flat L1 mascot across the app, boot screen, landing page, SVGs, PNGs, and ICOs. Favicons keep the black tile. No glow or blueprint decoration on the mark.
- Settings opens over the current chat. All six existing sections remain. Legacy settings links open the matching section. Search, Escape, focus restoration, nested picker portals, and mobile layout remain available.
- Main chat bubbles, text sizes, message grouping, and width estimates remain. Figtree sets the interface, Bricolage sets headings, and Remix supplies interface icons. Specialized provider, file, and recipe artwork keeps its existing generators.
- Sidebar and composer use the selected layout. The right tool pane opens directly, with no entrance motion.

## Integration fixes

The implementation started from main at 6167d2b1, rather than the source PR's older fork at 8c2ae5ee. The recovery audit compared every overlapping frontend file against stabilization commit e21a0548.

Three overwritten main fixes were restored: dragging folders into the composer, clearing file search when changing rooms, and resetting command-palette selection on open or submenu change. Main's room cache, reconnect, queued sends, attachment uploads, catalog cache, unread handling, and snapshot handover remain.

Current fetched main is 24d34537, version 0.4.3. Its later changes affect release/deploy workflows and the version, with no newer frontend changes. Those commits are incorporated before delivery.

Additional fixes from recovery include a local Suspense boundary around the lazy model picker, exclusive virtualizer/native scroll correction, recoverable provider catalog loading, immediate model selection persistence, readable light-theme setup progress, and retryable Cloudflare token instructions. Hosted sign-in uses one honest Clerk action instead of two buttons that both opened the same generic modal.
