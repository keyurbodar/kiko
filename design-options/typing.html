how an agent shows it's working

kiko never streams text. a reply lands as whole bubbles, one per paragraph, with a typing bubble between them, the way telegram and kat do. so the shimmer line and the growing draft bubble go. each option below keeps the kat typing bubble (68 by 34, 8px dots) and the same vector birds as the sidebar, and differs in how it tells you what the agent is doing. every column runs the same script on a loop.

a. kat dots + caption

the plain kat bubble, always the same wave. the agent's bird sits beside it, still, like on its messages. a muted line says what it's doing when it isn't just writing.

b. bird in the bubble

two dots, then the agent's own bird inside the bubble acting it out: pecking a laptop while writing, thought puffs while reading, a gear while editing or using a tool.

c. the dots act recommended

kat bubble, bird beside it. the three dots change how they move: a wave while writing, a slow scan while reading, a hop while editing, an orbit while using a tool. a caption only for anything slow.

what i'd ship

  • no growing text. the draft bubble goes. a long paragraph still arrives whole; while it's being written the agent just shows as typing.
  • option c's bubble. the kat bubble stays the one shape. the dots carry the act, so there's no extra icon or shiny line, and it still reads as "typing" at a glance.
  • the bird beside it, from the sidebar. vector, not pixel. it gives a tiny peek now and then so it reads as alive, and it's the same bird as on the agent's messages.
  • a caption only when it helps. "reading a web page" shows after the act runs past ~2s, plain muted text, no shimmer.
  • a team stacks rows. one typing bubble per working agent, each with its own bird and its own dots, up to three; then "and 2 others".
  • a reply pops out of the typing bubble. the typing bubble leaves and the message scales in from the same corner, so it feels like the bubble turned into the message.
