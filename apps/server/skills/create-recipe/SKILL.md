---
name: create-recipe
description: make or change one of the human's recipes in /home/recipes, when they ask for a new habit, a saved procedure, a recipe, or a skill, or want a recipe changed.
---
1. read /kiko/recipes.md. it has the file format and the rules.
2. say in one line what the recipe will do.
3. write /home/recipes/<name>/RECIPE.md. to change a built-in recipe, start from its file in /kiko/recipes/<name>/RECIPE.md.
4. offer to add it here with add_recipe. add_recipe checks the file and says what to fix.
