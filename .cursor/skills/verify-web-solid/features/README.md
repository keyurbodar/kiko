# Feature map — web-solid

One file per user-facing feature. Each answers, from the reader's point of view: what it is,
how to reach it, how to drive it, and what observable end state proves it works.

The map is the maintained source of verification. A proof that drives one convenient entry
point is incomplete when the map lists others.
